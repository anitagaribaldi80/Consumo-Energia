# Super Calculadora de Consumo de Energia
⚡Programa em Python para calcular o consumo mensal de energia de aparelhos eletronicos. ⚡
A linguagem utilizada foi o Python e a ideia de calculo foi bem simples, consumoMensal = (potencia * horasDia * 30) / 1000
Coloquei tambem o valor desse consumo em reais, usando o valor do KwH na cidade onde eu moro, Sorocaba, como exemplo, pq ainda assim voc"e pode utilizar o KwH da sua localidade.🏠🌆
